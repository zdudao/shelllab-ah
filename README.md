# 水豚天堂 · 拍卖行行情数据

这是「水豚天堂数据库」桌面程序的**拍卖行行情数据仓库**。
玩家在软件里点「投稿行情」，数据会以文件形式提交到 `incoming/`，
下面的机器人会自动合并进 `prices.csv`，所有人打开软件就能拉到最新行情。

## 数据从哪来

游戏里的 AUX 拍卖行插件会记录扫描过的价格，但它**只保留最近约 8 天**。
本仓库把不同玩家各自那 8 天拼起来，就能得到更长、更完整的行情历史。

## 文件格式

投稿包和总表 `prices.csv` 用同一种格式：

```
# realm=Eversong Wilds faction=Alliance
871,1793376000,88888888
4411,1793376000,60000000
```

- `#` 开头的是元信息，标明服务器和阵营
- 数据行三列：**物品ID, 日期(天级Unix时间戳), 价格(铜币)**（10000 铜 = 1 金）

## 隐私

导出和投稿的内容**只包含物品ID、日期、价格**，
不含角色名、金币数、账号信息等任何个人数据。

## 目录

| 路径 | 作用 |
|---|---|
| `incoming/` | 玩家投稿的文件，合并后自动清空 |
| `prices.csv` | 合并后的总表，软件从这里下载 |
| `scripts/merge.py` | 合并脚本 |
| `.github/workflows/merge.yml` | 自动合并流程 |
